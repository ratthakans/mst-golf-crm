## 1 · ภาพรวม

**MST Golf Platform** คือระบบสมาชิก แต้มสะสม และจองซิมกอล์ฟของ MST Golf Thailand (ชาญอิสสระ ทาวเวอร์ 1) เป็นแพลตฟอร์มของ ORIONS ที่ MST เป็น tenant แรก

| ผู้ใช้ | ใช้ผ่าน | ทำอะไร |
|---|---|---|
| ลูกค้า | LINE OA (ปุ่ม Rich Menu) · เว็บไซต์ | สมัครสมาชิก · บัตรสมาชิก QR · ดูแต้มและระดับ · จองซิม · รับข้อความแจ้งเตือน |
| พนักงาน MST (5 ตำแหน่ง) | หลังบ้าน | เพิ่มสมาชิก · นำเข้ายอดขาย POS · ตารางซิม · บทความเว็บ · ตั้งค่า |
| ทีม LINE Marketing | LINE OA Manager | Rich Menu · auto reply · แชต · บรอดแคสต์ — ไม่ต้องแตะระบบนี้ |

ลูกค้า 1 คน = รหัสสมาชิกเดียว (`MST00000001`) ผูก LINE UID และเบอร์โทรไว้ด้วยกัน ไม่ว่าเข้ามาทางไหนก็เป็นคนเดิม

## 2 · สถาปัตยกรรม

```
LINE OA (ทีม LINE) ── Rich Menu ปุ่ม A+B → liff.line.me/<liffId>/member
                                 ปุ่ม D   → liff.line.me/<liffId>/booking
        │ Messaging API (push)                     │ LIFF / LINE Login
        ▼                                          ▼
┌────────────────────────────┐        ┌────────────────────────────────┐
│ apps/web-admin  (หลังบ้าน)  │        │ apps/web  (เว็บไซต์ + หน้าลูกค้า) │
│ Vercel "mst-golf-crm"      │        │ Vercel "mst-golf-web"          │
│ /api/*  /api/cron/*        │        │ /  /services  /golf-simulator  │
│                            │        │ /blog  /app/member /app/booking│
└─────────────┬──────────────┘        └───────────────┬────────────────┘
              └──────────── packages/core ───────────┘
                 ตรรกะธุรกิจทั้งหมด (สมาชิก แต้ม ระดับ POS จอง ข้อความ LINE)
                              packages/database (Prisma, forOrg)
                              Neon Postgres · Singapore
```

- **สองแอป หนึ่งแกนกลาง** — route handler แค่ตรวจสิทธิ์แล้วเรียก `@mstgolf/core` ทุกกติกาอยู่ที่เดียว ทดสอบได้โดยไม่ต้องมีเว็บ
- **Multi-tenant** — ทุกตารางมี `orgId` ทุก query ผ่าน `forOrg(orgId)` แอปรู้ว่าเป็นร้านไหนจาก `ORG_SLUG`
- **ฐานข้อมูลแยกตามสภาพแวดล้อม** — Neon ฐานเดียว แยก Postgres schema: `public` = production · `preview` · `dev` · `test_core`

### การยืนยันตัวลูกค้า

```
ใน LINE       liff.init() → getIDToken()           (ล็อกอินอัตโนมัติ)
ในเบราว์เซอร์  liff.init() → liff.login() → กลับมา → getIDToken()
        ↓
POST /api/me/session  → ตรวจ ID token กับ LINE (client_id = LINE Login channel)
        → ได้ LINE UID → ตั้ง cookie mst_member (30 วัน)
        → ทุก /api/me/* หา member จาก UID ใน cookie เท่านั้น ไม่รับ id จาก request
```

หน้า `/app/member` และ `/app/booking` เป็นหน้าเดียวกันทั้งใน LINE และบนเว็บ บัญชีเดียวกัน

## 3 · ระบบสมาชิก

### 3.1 หน้าลูกค้า (`/app/member`)

| สถานะ | แสดง |
|---|---|
| ยังไม่ล็อกอิน | ปุ่มล็อกอินด้วย LINE (ใน LINE ข้ามขั้นนี้) |
| ล็อกอินแล้ว ยังไม่เป็นสมาชิก | ฟอร์มสมัคร: ชื่อ-นามสกุล · เบอร์มือถือ · วันเกิด (ไม่บังคับ — ได้แต้ม ×2 เดือนเกิด) · อีเมล (ไม่บังคับ) · ยอมรับข้อกำหนด (บังคับ) · รับข่าวสาร (เลือกได้) |
| สมาชิก | แท็บ **บัตร**: ชื่อ ระดับ รหัส QR แต้ม แถบ "อีก ฿X ถึง Silver" ปุ่มเพิ่มความสว่างสำหรับสแกนที่เคาน์เตอร์ · **แต้ม**: ประวัติพร้อมเหตุผล · **โปรไฟล์**: แก้ชื่อ อีเมล วันเกิด (ครั้งเดียว) รับข่าวสาร |

### 3.2 กติกาการสมัคร

```
เบอร์ → ทำให้เป็น 0XXXXXXXXX (06/08/09) ไม่งั้น "เบอร์ไม่ถูกต้อง"
├ เบอร์ใหม่                         → สร้างสมาชิก + ผูก LINE + เบอร์ (ยังไม่ยืนยัน) + แต้มต้อนรับ
├ เบอร์มีอยู่ ยังไม่มี LINE           → ผูก LINE เข้าบัญชีเดิม (สมัครที่เคาน์เตอร์หรือมาจาก POS)
│                                     ได้แต้ม ประวัติ ระดับเดิม · แต้มต้อนรับให้ครั้งเดียวต่อคน
└ เบอร์มีอยู่ ผูก LINE อื่นแล้ว       → ไม่ผูก แจ้ง "ติดต่อร้าน" + เข้าคิวตรวจสอบ (เบอร์ชนกัน)
```

- เบอร์ **ยืนยันแล้ว** เมื่อบิลแรกที่มีเบอร์นี้เข้าระบบ หรือพนักงานสร้าง/แก้ให้ที่เคาน์เตอร์ (ไม่มี OTP)
- ทุกการสมัครบันทึกความยินยอม TERMS + MARKETING พร้อมเวอร์ชันข้อความที่ลูกค้าเห็นจริง
- ช่องทางที่มา: `LINE` · `WEB` · `COUNTER` · `POS` · `IMPORT`

### 3.3 แต้มและระดับ

| | ค่าตั้งต้น (แก้ได้ใน ตั้งค่า) |
|---|---|
| แต้มต้อนรับ | 1,600 |
| แต้มฐาน | 1 แต้มต่อ 1 บาท (ยอดสุทธิ ไม่รวมสินค้าที่ตั้งยกเว้น) |
| อัตราตามระดับ | Member ×1 · Silver ×1.25 · Gold ×1.5 |
| เดือนเกิด | แต้มฐาน ×2 (ต้องมีวันเกิดในโปรไฟล์) |
| Silver | ยอดซื้อ 12 เดือน ≥ ฿100,000 · ส่วนลดร้าน 5% · ส่วนลดซิม 10% · จองล่วงหน้า 14 วัน |
| Gold | ยอดซื้อ 12 เดือน ≥ ฿1,000,000 · ส่วนลดร้าน 10% · ส่วนลดซิม 20% · จองล่วงหน้า 21 วัน |

```
แต้มบิล = floor(ยอดที่ได้แต้ม × แต้มต่อบาท × อัตราของระดับ "ก่อน" บิลนี้)
        + แต้มฐาน × (ตัวคูณเดือนเกิด − 1)   ถ้าเป็นเดือนเกิด
```

- **ระดับคิดจากยอดซื้อสุทธิ 12 เดือนย้อนหลัง ไม่ใช่แต้มคงเหลือ**
- **ขึ้นทันที** เมื่อบิลทำให้ถึงเกณฑ์ (บิลที่ทำให้ขึ้นได้อัตราเดิม บิลถัดไปได้อัตราใหม่) + ข้อความ LINE
- **ลงเดือนละครั้ง** วันที่ 1 ตอนตี 2 ไม่ลงกลางเดือน
- ส่วนลดร้าน/ซิม พนักงานให้ที่ POS/ตอนเช็กอิน ดูระดับจากบัตร — ระบบไม่คุม POS
- Phase 1 **สะสมอย่างเดียว** ไม่มีการแลก จึงยังไม่มีแต้มหมดอายุ
- แต้มเปลี่ยนผ่านรายการ `PointTransaction` เท่านั้น ยอดคงเหลือตรงกับผลรวมรายการเสมอ (ตรวจทุกคืน)

### 3.4 ข้อความ LINE ของระบบสมาชิก

| ข้อความ | ส่งเมื่อ |
|---|---|
| ต้อนรับ + รหัสสมาชิก + แต้มต้อนรับ | สมัครเสร็จ (LINE / เว็บ) |
| ได้รับแต้มแล้ว — ยอด แต้มที่ได้ คงเหลือ อีกเท่าไรถึงระดับถัดไป | หลังนำเข้า POS · 1 ข้อความต่อคนต่อรอบ รวมทุกบิล |
| ยินดีด้วย เลื่อนระดับ + สิทธิ์ใหม่ | ยอดถึงเกณฑ์ |

### 3.5 หลังบ้าน — สมาชิก

- **ค้นหา** ชื่อ / เบอร์ / รหัส · กรองระดับ · ผูก LINE หรือยัง · ช่องทางสมัคร
- **ข้อมูลลูกค้าในหน้าเดียว** — รูป ชื่อ ระดับ แต้ม ยอด 12 เดือน ความคืบหน้าสู่ระดับถัดไป สิทธิ์ของระดับ · แท็บ ไทม์ไลน์ · บิล (กางดูรายการสินค้า) · แต้ม · การจองซิม · ตัวตนและ PDPA · บันทึกการแก้ไข
- **เพิ่มสมาชิกที่เคาน์เตอร์** — ได้แต้มต้อนรับเหมือนสมัครใน LINE · เบอร์ซ้ำพาไปข้อมูลเดิม · แนบรูปได้
- **ลิงก์ + QR สมัครสมาชิก** สำหรับตั้งที่เคาน์เตอร์ (ลิงก์เดียวกับปุ่ม A+B)
- **ปรับแต้ม** — ต้องมีเหตุผล (ลูกค้าเห็นในประวัติ) · ผู้จัดการสาขา/บริการลูกค้า ครั้งละไม่เกิน ±1,000 · ผู้ดูแลระบบไม่จำกัด
- **แก้ข้อมูล** รวมเปลี่ยนเบอร์ · **รูปโปรไฟล์** เก็บแบบส่วนตัว
- **รวมบัญชีซ้ำ** (ผู้ดูแลระบบ) · **ลบข้อมูล PDPA** (ผู้ดูแลระบบ) · บริการลูกค้าส่ง **คำขอ** เข้าคิวตรวจสอบ

### 4.1 ตาราง

| กลุ่ม | ตาราง |
|---|---|
| แพลตฟอร์ม | Organization (settings JSON) · User · AuditLog · Counter · Store |

เงินเก็บเป็น **สตางค์ (จำนวนเต็ม)** ทุกคอลัมน์ที่ลงท้าย `Satang` · เวลาธุรกิจเป็นเวลากรุงเทพฯ

### 4.2 กติกาข้อมูล

- **1 เบอร์ / 1 LINE UID ผูกได้สมาชิกคนเดียว** (unique ในฐานข้อมูล)
- **รหัสสมาชิก** `MST` + 8 หลักเรียงลำดับ ไม่เปลี่ยน ไม่นำกลับมาใช้
- **กันจองซ้อน** ในฐานข้อมูล: 1 lane 1 ชั่วโมงมีการจองที่ยังมีผลได้ 1 รายการ
- **แต้มต้อนรับให้ครั้งเดียวต่อคน** และ **แต่ละบิลให้แต้มครั้งเดียว** — บังคับในฐานข้อมูล
- **รวมบัญชี**: บัญชีที่เก็บไว้ได้ตัวตน บิล การจอง ประวัติ แต้ม (หักแต้มต้อนรับที่ได้ซ้ำ) · ผูก LINE คนละบัญชีทั้งคู่ = รวมไม่ได้
- **ลบข้อมูล PDPA**: ลบตัวตน ชื่อ วันเกิด อีเมล รูป · ยกเลิกการจองที่ยังไม่ถึงเวลา · บิลเก็บไว้ทางบัญชีแต่ไม่ผูกตัวบุคคล · เบอร์นั้นสมัครใหม่ได้
- ทุกการกระทำของพนักงานที่แก้สมาชิก แต้ม การจอง การนำเข้า การตั้งค่า เขียน **บันทึกการใช้งาน** (ใคร อะไร ก่อน/หลัง เหตุผล IP)

### 4.4 การสำรองข้อมูล

- **ทุกคืน 03:00** GitHub Actions ทำ `pg_dump` ของ production → เข้ารหัส → Blob ส่วนตัว เก็บ 30 วัน

## 5 · ระบบจอง Golf Simulator

### 5.1 กติกา (ค่าตั้งต้น แก้ได้ใน ตั้งค่า › การจองซิม)

| กติกา | ค่า |
|---|---|
| Lane | 3 lane · สูงสุด 3 คนต่อ lane · ฿1,000/ชม. |
| ช่องเวลา | 1 ชั่วโมงตรงชั่วโมง ตามเวลาเปิดร้าน (ตั้งต่อวันในสัปดาห์) |
| จองล่วงหน้า | ตามระดับ: 14 วัน · Gold 21 วัน |
| จำกัดต่อคน | 2 ช่องต่อวัน · การจองที่ยังไม่ถึงเวลา 4 รายการ |
| ราคา | ราคา lane − ส่วนลดซิมของระดับ · แสดงก่อนยืนยัน · ชำระที่ร้าน |
| ถือช่อง | 5 นาทีระหว่างกดยืนยัน · เลยเวลาช่องว่างเอง |
| ยกเลิกเอง | ก่อนเวลาจอง 2 ชั่วโมง · หลังจากนั้นติดต่อร้าน |
| ไม่มาตามนัด | พนักงานบันทึกได้หลังเริ่ม 15 นาที · นับไว้ในข้อมูลลูกค้า |
| ผู้จอง | ลูกค้าจองเองต้องเป็นสมาชิก · walk-in / โทรจอง ไม่ต้องเป็นสมาชิก (เบอร์ตรงสมาชิกผูกให้เอง) |

### 5.2 ลูกค้าจอง (`/app/booking` — ปุ่ม D หรือเว็บ)

```
เลือกวัน → ตาราง lane × ชั่วโมง (ว่าง · เต็ม · ปิด · ผ่านไปแล้ว — ไม่บอกว่าใครจอง)
 → แตะช่อง → จำนวนคน → ถือช่อง 5:00 นับถอยหลัง + ราคา
 → ยืนยัน → ข้อความ LINE ยืนยัน · เตือนก่อน 2 ชม.
 ยังไม่เป็นสมาชิก → พาไปสมัคร แล้วกลับมาหน้าจอง
 "การจองของฉัน" อยู่หน้าเดียวกัน ยกเลิกได้ตามกติกา
```

### 5.3 ข้อความ LINE ของระบบจอง

ยืนยันการจอง · เตือนก่อนเวลา (ส่งครั้งเดียว ข้ามถ้าจองภายในช่วงเตือน) · ยกเลิก (ลูกค้าหรือพนักงาน พร้อมเหตุผล) · ย้ายเวลา/lane

### 5.4 หลังบ้าน — ซิมกอล์ฟ

- ตาราง **รายวัน** (lane × ชั่วโมง) และ **รายสัปดาห์** · ป้ายสีตามสถานะ และป้ายที่มา LINE / เว็บไซต์ / Walk-in / โทรจอง
- แตะช่องว่าง → จองให้ (ค้นสมาชิก หรือชื่อ+เบอร์) · เลือกเช็กอินเลยได้
- **ลากการ์ด** ย้ายเวลา/lane · ช่องปลายทางไม่ว่างย้ายไม่ได้
- แตะการจอง → เช็กอินพร้อมยอดที่รับ · บันทึกยอด · ไม่มาตามนัด · ยกเลิก (เหตุผลส่งถึงลูกค้า)
